# 🔮 Mega-Sena Intelligence AI - Dashboard Pro v2.0

Este é um projeto completo de Ciência de Dados e Inteligência Artificial que analisa o comportamento estatístico e estocástico dos sorteios da Mega-Sena. O sistema foi desenvolvido com uma interface gráfica responsiva via **Streamlit**, permitindo que o aplicativo seja executado perfeitamente tanto em computadores quanto em dispositivos móveis (smartphones e tablets).

---

## 🚀 Funcionalidades Principais

*   **🎲 Gerador Estatístico Ponderado:** Algoritmo que calcula a frequência de saída de cada dezena no histórico e utiliza amostragem ponderada probabilística para sugerir novos jogos.
*   **🛡️ Filtros de Restrição Inteligentes:** O sistema analisa e descarta automaticamente combinações com padrões extremamente raros na história real das loterias, tais como:
    *   **Balanço de Paridade:** Evita cartões compostos apenas por números pares ou apenas por ímpares.
    *   **Dispersão por Quadrantes:** Garante que os números gerados fiquem espalhados geograficamente pelas quatro regiões do volante de papel.
*   **🟩 Volante Virtual Interativo:** Interface dinâmica em HTML que acende em verde neon as dezenas do cartão selecionado, facilitando a análise visual da dispersão espacial.
*   **🔍 Detetive de Jogos Históricos:** Permite ao usuário inserir suas próprias dezenas favoritas para rodar testes computacionais de conformidade e verificar se a combinação já ganhou prêmios anteriores.
*   **📥 Exportação para Excel:** Botão integrado para baixar instantaneamente os jogos gerados formatados em uma planilha do Excel (`.xlsx`).

## 🛠️ Tecnologias Utilizadas

O motor do sistema foi construído utilizando o ecossistema moderno de dados do **Python**:

*   **Python** (Linguagem principal)
*   **Streamlit** (Interface gráfica web e execução mobile)
*   **Pandas & NumPy** (Engenharia de dados, matrizes de memória e manipulação de tabelas)
*   **Matplotlib & Seaborn** (Renderização do mapa de calor e gráficos analíticos)
*   **Requests** (Consumo e tratamento de APIs de microsserviços)
*   **XlsxWriter** (Geração e empacotamento de planilhas do Excel)

---

## 📱 Como Rodar este Projeto no Celular ou Computador

O projeto está configurado para publicação automatizada em nuvem. Para acessá-lo diretamente do seu celular:

1. Acesse o painel do **Streamlit Community Cloud**.
2. O aplicativo instalará as dependências do arquivo `requirements.txt` em segundo plano.
3. O servidor gerará um link público seguro (ex: `https://streamlit.app`) otimizado para navegadores mobile.
